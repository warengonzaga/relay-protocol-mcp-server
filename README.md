# Relay Protocol MCP Server

The first community-built MCP server for Relay Protocol.

## Status: discontinued

Relay Protocol is still active. This community project is retired because its API access is changing, and Relay's team now provides its own MCP server.

Read Relay's [Requests v3 migration guide](https://docs.relay.link/references/api/api_guides/migrating-to-requests-v3).

This server no longer fetches Relay data. It only returns a retirement notice; the original source remains here for reference.
